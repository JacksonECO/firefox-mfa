10. Outro esquema de id sequencial

Igual ao exemplo 9, mas com outro prefixo: de token-input-token-0 a token-input-token-5. Serve para testar uma config que cobre dois esquemas de id ao mesmo tempo.

Seletor para configurar

input[id^="token-input-token-"]

Sozinho, este seletor de prefixo casa as 6 caixas desta página (modo "um dígito por caixa").

Cobrir os dois esquemas com uma config só

Para a mesma configuração funcionar tanto aqui quanto no exemplo 9 (token-input-mfa-…), combine os dois prefixos com vírgula — o querySelectorAll casa a união:

input[id^="token-input-mfa-"], input[id^="token-input-token-"]

Em uma página de login real só um dos esquemas existe, então o combinado casa exatamente as 6 caixas presentes. Use o seletor combinado como padrão (ou por domínio).
