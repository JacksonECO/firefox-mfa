9. Seis caixas com id sequencial

Seis <input maxlength="1">, cada um com um id único e um contador no final: de token-input-mfa-0 a token-input-mfa-5. Comum em sites que geram um id por dígito.

Seletor para configurar

input[id^="token-input-mfa-"]

O ^= significa "id que começa com". Assim um seletor só casa as 6 caixas (token-input-mfa-0 … token-input-mfa-5) sem precisar listar cada id. Casa 6 elementos (≥ 6) → modo "um dígito por caixa", com input/change e Enter na última.

Alternativa (mais verbosa) listando os ids: 

#token-input-mfa-0, #token-input-mfa-1, #token-input-mfa-2,
#token-input-mfa-3, #token-input-mfa-4, #token-input-mfa-5

Para uma config cobrir dois esquemas de id ao mesmo tempo (ex.: este e o token-input-token-… do exemplo 10), combine os prefixos com vírgula:

input[id^="token-input-mfa-"], input[id^="token-input-token-"]
