3. Campo único identificado por name

Um só <input name="code">. Útil quando o campo não tem id estável, mas tem um name previsível.

Seletor para configurar

input[name="code"]

Casa 1 elemento → o código inteiro vai neste campo, seguido de input/change e Enter.

Preencha pela extensão ou digite e aperte Enter — um modal mostra o resultado.
