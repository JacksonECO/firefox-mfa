      Autopreenchimento na página

      Quando houver só 1 MFA para o site, insere o código no campo indicado e tenta confirmar com Enter. Só o código (nunca o segredo) é inserido na página. O seletor CSS aponta o(s) campo(s) de código — ex.: #otp, input[name="code"] ou input[autocomplete="one-time-code"]. Para 6 caixas separadas, use um seletor que case os 6 inputs (ex.: .otp-box). Guia completo em docs/autopreenchimento.md.

      Autopreenchimento de login

      Ao abrir a extensão, preenche o e-mail/usuário e a senha da conta principal do site. A senha vai do processo de fundo direto para a página — nunca passa por esta janela. Os seletores padrão cobrem a maioria dos formulários; quando não casarem, defina um seletor só para aquele domínio.

      ⚠️ O envio automático pode disparar a ação errada em páginas que usam Enter para outra coisa. Desligado por padrão.
